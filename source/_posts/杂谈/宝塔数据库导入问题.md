# 宝塔数据库导入问题

## 1. 宝塔使用docker数据库的时候，会无法使用导入功能，写一下解决办法

这种情况非常少，一般人不会遇到
宝塔不在本地安装mysql数据库，而是在docker里安装发现的一点问题。
因为需要5.7和8.0两个版本的mysql数据库，所以用docker部署数据库，导致出现无法导入的情况

### 解决方法
首先在终端执行
```
apt-get install mariadb-client
```
然后确认是否安装成功
```
which mysqldump
```
如果出现
```
/usr/bin/mysqldump
```
则表示安装成功

```
mysqldump --help
```
用来检查命令是否可用

最后重启宝塔

```
bt restart
```
## 结束

等待重启成功，就可以了
